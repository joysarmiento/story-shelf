## What it shows

- Presentation (0:00 to 4:48)

  - **0:00** What Story Shelf is and who it is for: Maria Andretti Sarmiento presents a cozy media tracker and personal journal for books, comics, movies, and series
  - **0:25** The problem: media progress, ratings, and emotional memories are scattered across multiple apps or forgotten completely over time
  - **1:36** Feature overview: unified library, quick auto-filling search, chapter/episode journaling with mood tagging, and daily home screen memories
  - **2:44** User journey flow: six main steps from opening the shelf to saving an emotional memory
  - **3:20** Catalog search and adding: choosing medium types, searching titles, auto-filling details, and navigating forms
  - **3:59** Progress tracking & journaling: tracking reading page counts, writing chapter notes, selecting moods, and reviewing saved memory lists

- Live demo (4:48 to 21:00)

  - **4:48** Live demo begins with overview of five screen groups: Browse, Add, Track, Journal, and Settings
  - **4:57** Start screen, authentication flow, sign-up form, forgot password screen, and error state for wrong credentials
  - **6:11** Dashboard view: daily rotating "Memory From This Day" cards, active "Continue Stories", and recent memories
  - **7:29** Page-flip animations when switching tabs, and filtering library by medium types
  - **8:03** Library features: global search, empty states, favoriting stories, filtering by status, and sorting alphabetically or by latest added
  - **9:54** Memories screen: browsing all user-written entries, searching text, and filtering by date or mood tags
  - **10:42** Profile & dashboard stats: viewing total stories, completed counts, memory counts, average mood, and medium distribution
  - **11:11** Manual story creation: uploading book cover image via gallery or web link with real-time preview, and setting progress metadata
  - **13:40** Adding a story via API search: querying Open Library, selecting a title, pre-filling forms, and saving to library
  - **14:46** Story details view: progress bars, page count updates, favoriting, deletion options, and memory list view
  - **15:49** Note-style journaling screen: adding custom overall/chapter notes, timestamps, mood selectors, and quote attachments
  - **17:27** Interactive memory view: note auto-saving feature while typing and updating mood tags
  - **18:28** Settings screen: updating profile information and user picture
  - **19:09** Accessibility preferences: enabling high contrast mode and toggling text size adjustments
  - **19:41** Account settings & safeguards: prompt confirmations before signing out or deleting accounts
  - **20:12** Unsaved changes safeguard: prompt modal confirming memory discard when navigating away

- Tech stack & development process (21:00 to 27:20)

  - **21:00** Technical architecture: Flutter, Dart, Supabase backend (Postgres, Row Level Security, Auth), external media APIs, and GitHub Pages hosting
  - **22:13** AI usage and workflow breakdown: 5-step process (mockup, ask, draft, rework, log) and human-coded vs. AI-assisted components
  - **23:28** Challenges and solutions: bottom navbar gap layout fix, handling navigator return values for status filters, and redesigning forms into note-style journaling pages
  - **26:18** Current limitations and missing features: lack of offline mode, pull-to-refresh missing, and movie time tracking limits
  - **26:47** Future roadmap: offline cache, pull-to-refresh, expanded statistics, minute-based movie progress, and custom collections
