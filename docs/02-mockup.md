# Mockup and wireframes of Story Shelf

The visual plan for this app. Your wireframes answered what goes where; the
mockup shows what it looks like.

## Mockup

| Screen | Screen Details |
|---|---|
| **01 Start**<br><br>![01 Start](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/01-start.png) | **Purpose**<br>The Start screen introduces Story Shelf to new users and provides the entry point into the application. It presents the app's identity and gives the user an option to begin using the app.<br><br>**User Actions and Flow**<br>• "Get Started" button: Navigates the user to the Login screen.<br>• The user can proceed to sign in to an existing account or create a new account from the Login screen.<br><br>**Navigation**<br>The Start screen is the initial screen displayed when the application is opened. The Get Started button serves as the primary action and leads to the Login screen. |
| | |
| **02 Log in**<br><br>![02 Log in](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/02-login.png) | **Purpose**<br>The Login screen allows existing users to access their Story Shelf account using their email/username and password.<br><br>**User Actions and Flow**<br>• Email / Username text field: Allows the user to enter the email address or username associated with their account.<br>• Password text field: Allows the user to enter their account password.<br>• Eye icon: Shows or hides the entered password.<br>• "Forgot Password?" link: Navigates to the Reset Password screen.<br>• "Sign In" button: Authenticates the user and navigates to the Home screen.<br>• "Sign up" link: Navigates to the Sign Up screen.<br><br>**Navigation**<br>The Login screen is the main authentication screen after the Start screen. Users can either continue to Home by signing in, recover their account through Reset Password, or create a new account through Sign Up. |
|---|---|
| **03 Reset Password**<br><br>![03 Reset Password](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/03-reset_password.png) | **Purpose**<br>The Reset Password screen allows users who cannot access their account to request a password reset link using the email associated with their Story Shelf account.<br><br>**User Actions and Flow**<br>• Email text field: Allows the user to enter the email address associated with their account.<br>• "Send Reset Link" button: Sends a password reset verification email and confirms to the user it was sent.<br>• Back button: Returns the user to 2. Login.<br><br>**Navigation**<br>The screen is accessed through the Forgot Password? link on the Login screen. After requesting a reset link, the user can follow the instructions sent to their email to regain access to their account. |
|---|---|
| **04 Sign up**<br><br>![04 Sign up](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/04-signup.png) | **Purpose**<br>The Sign Up screen allows new users to create a Story Shelf account.<br><br>**User Actions and Flow**<br>• Name text field: Allows the user to enter their name.<br>• Email text field: Allows the user to enter an email address for their account.<br>• Password text field: Allows the user to create a password.<br>• Eye icon: Shows or hides the entered password.<br>• "Sign Up" button: Creates the user's account and navigates to the Home screen.<br>• "Login" link: Returns the user to the Login screen if they already have an account.<br><br>**Navigation**<br>The Sign Up screen is accessed from the Login screen. It provides an alternative authentication path for new users before they enter the main application. |
|---|---|
| **05 Home**<br><br>![05 Home](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/05-home.png) | **Purpose**<br>The Home screen provides the user with a personalized overview of their Story Shelf. It allows users to quickly see their featured memory, continue unfinished stories, and revisit recently created memories.<br><br>**User Actions and Flow**<br>• "Memory of the Day" card: Displays a randomly or algorithmically selected past memory; tapping it navigates to that memory's parent Story Details.<br>• "Continue Your Stories" cards: Each card shows a story's medium, title, and progress bar; tapping a card navigates to that story's Story Details.<br>• "Continue Your Stories" — See all: Navigates to Library.<br>• "Recent Memories" cards: Each card shows a memory's title, type, date, and a one-sentence excerpt; tapping a card navigates to that memory's Memory Details.<br>• Bottom navigation bar: Home / Library / Search / Profile icons switch between the app's four main sections.<br><br>**Navigation**<br>Home serves as the main landing screen after authentication. It connects the user's current stories and memories to the main sections of Story Shelf through the bottom navigation bar. |
|---|---|
| **06 Library**<br><br>![06 Library](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/06-library.png) | **Purpose**<br>The Library allows users to view, organize, filter, and access all stories saved in their Story Shelf. It acts as the main collection-management area of the application.<br><br>**User Actions and Flow**<br>• Medium tabs (scrollable): Allows users to switch between All mediums and the different mediums represented in their collection.<br>• Heart button: Displays the list of favorited stories only. It combines with whatever medium and status filters are also active.<br>• Filter button: Opens a status filter (Not Started / Started / Completed) as a bottom sheet/modal over Library. It combines with medium and favorite filters rather than replacing them.<br>• Story cards: Navigates to that story's Story Details.<br>• Bottom navigation bar: Switches between Home / Library / Search / Profile.<br><br>*Example combined state:* "All" mediums + Favorites on + Completed selected → shows every favorited, completed story regardless of medium.<br><br>**Navigation**<br>Reached via the bottom navigation bar's Library icon, or via "See all" from Home's Continue Your Stories section. It serves as the main workspace for managing the user's saved stories. It also provides access to Add Story, story details, filtering, favorites, and the user's saved memories. |
|---|---|
| **07 Add Story**<br><br>![07 Add Story](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/07-add-story.png) | **Purpose**<br>Lets the user log a new story to their shelf with enough detail to track and later reflect on it.<br><br>**User Actions and Flow**<br>• Cover image field: Allows the user to add a cover image for the story.<br>• Title text field: Allows the user to enter the title of the story.<br>• Creator / Author text field: Allows the user to enter the creator, author, director, or other relevant person associated with the story.<br>• Release Year field: Allows the user to enter the story's release year.<br>• Medium selector: Allows the user to select the type of story.<br>• Status selector: Allows the user to indicate whether the story is not started, in progress, or completed.<br>• Progress field: Allows the user to enter their current progress depending on the medium:<br>&nbsp;&nbsp;&nbsp;◦ Book: Page 120 of 350<br>&nbsp;&nbsp;&nbsp;◦ Manhwa: Chapter 116 of 150<br>&nbsp;&nbsp;&nbsp;◦ Anime: Episode 8 of 24<br>• Rating: Allows the user to give the story a rating out of five stars.<br>• Save Story button: Saves the entered information and directs the user to Story Details Screen.<br>• Back button: Returns the user to the previous screen.<br><br>**Navigation**<br>Add Story is accessed from the + Add Story button in the Library. After saving, the user is taken directly to the newly created Story Details screen. |
|---|---|
| **08 Story Details**<br><br>![08 Story Details](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/07-add-story.png) | **Purpose**<br>The Story Details screen provides a complete overview of a selected story and connects the story to the personal memories the user has created about it.<br><br>**User Actions and Flow**<br>• Upper Section (cover image, medium, title, creator, release year): Static display.<br>• Update button for Status/Rating/Progress block: Navigates to Edit Story to allow editing or updating of the story information.<br>• Memory cards: Navigates to that memory's Memory Details.<br>• "+ New" button: Navigates to Add Memory, pre-associated with this story.<br>• Back button: Returns the user to the previous screen.<br><br>**Navigation**<br>Reached from any story card across Home, Library, and Search. Functions as the hub all memory-related actions branch from. |
|---|---|
| **09 Edit Story**<br><br>![09 Edit Story](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/09-edit-story.png) | **Purpose**<br>The Edit Story screen allows users to modify information about an existing story without creating a new story entry.<br><br>**User Actions and Flow**<br>• All fields (cover, title, creator/author, release year, medium, status, progress, rating): These are pre-filled and editable.<br>• Save Story button: Saves the changes and navigates the user to the Story Details screen with the updated information.<br>• Back button: Returns to the previous screen without saving.<br><br>**Navigation**<br>Edit Story is accessed through the Update action on Story Details. It is part of the story management flow and is not included in the main bottom navigation. |
|---|---|
| **10 Add Memory**<br><br>![10 Add Memory](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/10-add-memory.png) | **Purpose**<br>The Add Memory screen allows users to record a personal reaction, thought, or reflection about a story they have saved.<br><br>**User Actions and Flow**<br>• Heading + subtext ("Add Memory — for [Story Title]"): Confirms which story this belongs to.<br>• Type selector (overall/chapter/episode/volume): Selecting chapter, episode, or volume reveals a field for that number.<br>• Memory title field: Allows the user to give the memory a title.<br>• Memory content field: Allows the user to write their thoughts or reaction.<br>• Date field: Allows the user to specify when the memory was created.<br>• Save Memory button: Saves and navigates to that memory's Memory Details.<br>• Back button: Returns the user to the previous screen.<br><br>**Navigation**<br>Add Memory is accessed through + New Memory on Story Details. The memory is automatically associated with the story from which the user opened the form. |
|---|---|
| **11 Memory Details**<br><br>![11 Memory Details](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/11-memory-details.png) | **Purpose**<br>The Memory Details screen allows the user to read a complete personal memory associated with a saved story.<br><br>**User Actions and Flow**<br>• Header (parent story's medium, title, creator, release year): Static display.<br>• Memory content (title, unit type, date, full text): Static display.<br>• Edit button: Navigates to Edit Memory.<br>• Back button: Returns to the previous screen.<br><br>**Navigation**<br>Memory Details is accessed by selecting a memory from Story Details, Home's Recent Memories, or the Library Memories view. |
|---|---|
| **12 Edit Memory**<br><br>![12 Edit Memory](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/12-edit-memory.png) | **Purpose**<br>Lets the user revise a memory's type, title, content, or date after it's been saved.<br><br>**User Actions and Flow**<br>• All fields (Memory Type, Chapter/Episode/Volume, Memory Title, Memory Content, Date): These are pre-filled and editable.<br>• "Save Memory Edits" button: Saves and navigates to Memory Details with updated content.<br>• Back arrow: Returns to the previous screen without saving.<br><br>**Navigation**<br>Edit Memory is accessed through the Edit button on Memory Details. It is part of the memory management flow rather than a main navigation destination. |
|---|---|
| **13 Search**<br><br>![13 Search](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/13-search.png) | **Purpose**<br>The Search screen allows users to quickly locate stories in their personal Story Shelf without manually browsing the entire Library.<br><br>**User Actions and Flow**<br>• Search field: Allows the user to enter a story title or keyword.<br>• All tab: Displays results from all available mediums.<br>• Medium tabs (scrollable): Filters search scope to a specific medium.<br>• Story result: Navigates to the Story Details screen.<br>• Bottom navigation bar: Switches between Home / Library / Search / Profile.<br><br>**Navigation**<br>Search is accessed through the Search tab in the bottom navigation bar. It provides a faster alternative to browsing the complete Library. |
|---|---|
| **14 Profile**<br><br>![14 Profile](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/14-profile.png) | **Purpose**<br>The Profile screen gives the user an overview of their personal account and Story Shelf activity.<br><br>**User Actions and Flow**<br>• Profile photo/name/email/username: Static display. Profile photo is empty until edited while Username is auto-generated until edited.<br>• Stats dashboard (total stories, completed stories, total memories): Static display.<br>• Stories-by-medium dashboard: Static display.<br>• Settings icon: Navigates to Settings.<br>• Bottom navigation bar: Switches between Home / Library / Search / Profile.<br><br>**Navigation**<br>Profile is accessed through the **Profile** tab in the bottom navigation bar. It provides access to account settings and the user's Story Shelf statistics. |
|---|---|
| **15 Settings**<br><br>![15 Settings](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/15-settings.png) | **Purpose**<br>The Settings screen allows users to manage their profile, application preferences, and account.<br><br>**User Actions and Flow**<br>• "Edit Profile" row: Navigates to Edit Profile.<br>• Dark mode toggle: Switches the app's appearance between light and dark themes.<br>• "Sign Out" row: Logs out and navigates to Login.<br>• "Delete Account" row: Begins account deletion.<br><br>**Navigation**<br>Settings is accessed through the **Settings** icon on Profile. It contains account and application preferences rather than story-management functions. |
|---|---|
| **16 Edit Profile**<br><br>![16 Edit Profile](https://github.com/joysarmiento/story-shelf/blob/main/docs/assets/mockups/16-edit-profile.png) | **Purpose**<br>The Edit Profile screen allows users to update the personal information displayed on their Story Shelf profile.<br><br>**User Actions and Flow**<br>• Profile photo field: Upload or select a new photo.<br>• Name/Email/Username Field: These are pre-filled and editable.<br>• "Update Profile" button: Saves and navigates to Profile with updated info.<br>• Back button: Returns the user to the previous screen without saving.<br><br>**Navigation**<br>Edit Profile is accessed through Edit Profile in Settings. After saving, the updated information is reflected on the Profile screen. |
